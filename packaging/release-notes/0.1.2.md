## Working with threads

- **Queue messages while the agent works.** **⏎** sends your message when the agent is done; **⌘⏎** gives it to the agent after its current step. Queued messages wait above the composer, where you can edit or remove them.
- **Close threads instead of deleting them** (**⌘W**). A new, empty thread in the same folder offers them under **Resume**. Closed threads are deleted after 30 days (Settings ▸ Threads).
- **Rename a thread** with **⌘R**, File ▸ Rename Thread… or the sidebar row's menu. Your name sticks; a generated title doesn't replace it.
- **Find in a thread** with **⌘F**, then **⌘G** / **⇧⌘G** for the next and previous match.
- **Jump to a thread**: hold **⌘** to see each sidebar row's number and type it. **⌘⌥↑** / **⌘⌥↓** step through threads.
- New threads stay off the sidebar until their first message. The folder picker shows only before a thread's first message.
- Model and effort can be changed in a thread you reopened, before you write in it.
- Hiding the sidebar (**⌘B**) leaves only its toggle in the title bar; ⌘[, ⌘] and ⌘N still work.

## Replies

- **Code blocks** have syntax colours, a header with the language and a copy button, and wrap long lines at spaces with an indent.
- **Markdown** looks like the rest of Space: clearer heading sizes, quieter lists and task boxes, inline code as a small chip, links without underlines, visible quote bars, tables without the dark header, footnotes as superscript numbers.
- **Images** in replies show, from your Mac or the web (https).
- Your long messages fold after 20 lines, with Show more.

## Terminal

- **⌘J** shows and hides the terminal (⌃\` still works).
- Typing `exit` closes the terminal's tab, and the pane with its last tab.

## Fixes

- Opened from Spotlight or the Dock, Space starts in the folder you worked in last, not in `/`.
- ⌘A, ⌘X, ⌘C, ⌘V and ⌘Z work in text fields like the rename sheet (the Edit menu has them now).
- Only one Space runs at a time; opening it again brings the running one forward.
- Small layout fixes: tool and permission rows spaced evenly, less empty space under replies and the composer, and the Chat | Trajectory bar matches the terminal's.
