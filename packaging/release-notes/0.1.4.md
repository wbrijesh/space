## Files

- **Browse the thread's folder** in the right pane (⌘P): a tree that leaves out `.gitignore`d files, colors git changes and updates as files change. Type to search every path.
- **Open files in tabs** beside the tree and the terminals: code with syntax colors, Markdown rendered, images. Right-click a row for Open in, Reveal in Finder and Copy Path.
- **See what changed.** A file with uncommitted changes opens on **Changes**, its diff against the last commit; **Full file** shows the whole file with the changes in place.
- ⌘W closes the open file; ⌥⌘B shows or hides the right pane.

## Composer and transcript

- **Quote** part of a reply: select it, then click **Quote**, and answer it in your message.
- **Long pastes** (over 4,096 characters) become a "Pasted text" attachment instead of filling the input.
- The composer no longer flickers between one and two rows while the agent works.

## Threads

- **Open in** (title bar): open the thread's folder in your editor, Finder or terminal (⌘O), or copy its path.
- ⇧⌘P pins or unpins a thread; ⇧⌘C and ⇧⌘T show Chat and Trajectory.
- ⌘Q always asks before quitting, and says if threads are working or terminals are running something.
