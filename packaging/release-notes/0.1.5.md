## Claude Code

- **Space now runs on Claude Code**, through your signed-in `claude` CLI and your Claude subscription. It never uses an API key, and none of your own Claude Code setup (CLAUDE.md, skills, hooks, MCP servers, plugins, memory) is loaded.
- **Slash commands:** type `/` for the menu. `/compact`, `/context` and `/goal` run as Claude Code's own.
- Tool calls now run without asking: the permissions plugin is gone.
- Threads from earlier versions open as before, but continue in a new session.

## Right pane

- **One strip of tabs.** The tree, files, terminals, Changes and side chats are all tabs. **+** (⌘T) opens a new tab: search the folder's files, or pick what to open, each with its shortcut, plus recent files. Closing the last tab shows a new tab; closing that hides the pane.
- **Changes** (⌃⇧G): the folder's uncommitted files and their diffs, then Commit (Claude writes the message; Undo until it's pushed), Push, Pull and Create PR (Claude writes the title and description).
- **Side chats** (⇧⌘L, or `/btw`): a read-only conversation about the thread that keeps up with it. Have as many as you like; each is named after its first message and kept until you delete it from a new tab.
- **A fixed width** you set by dragging its edge, remembered across launches. Maximize it (⇧⌘↩) to fill the window.
- **Two-finger swipe** left shows the pane and right hides it; a second swipe maximizes or restores it. Settings ▸ Trackpad moves the gesture to the sidebar or turns it off.

## Window

- **The chat keeps at least 600 px.** As the window narrows, the right pane closes, then the sidebar; widening brings them back.
- **Trajectory** is a button in the title bar (⇧⌘T) instead of a tab bar; Esc goes back to the chat.
- **Branches:** the folder menu shows the branch and lets you switch to one or create one.
- **Settings** lists its sections in the sidebar.
- ⌘'s row numbers in the sidebar show only after holding ⌘ for a moment.
- A quote above a sent message is as wide as the message.
