## Terminal

A terminal in the app, so you don't need a separate one beside it.

- **⌃`** opens the current thread's terminal pane on the right, with a shell in the thread's project folder. Press it again from the terminal to hide the pane.
- Each thread has its own terminals. Tabs are named after what's running, and a dot marks output you haven't seen. **⌘T** opens another tab, **⌘W** closes one (it asks first if something is running), **⌃Tab** switches tabs and **⌘⇧↩** maximizes the pane.
- Hidden terminals keep running. Threads with something running show a terminal mark in the sidebar.
- Copy and paste, ⌘K to clear, ⌘-click links, mouse support in programs like vim and htop, and full colour. The background matches the thread's.
- When a shell exits, press Enter for a new one. ⌘Q asks before quitting if a program is still running in a terminal.
